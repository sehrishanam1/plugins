Advanced customizable WordPress blocks — Counter, Pricing Table, Testimonial Carousel, Tabs, Icon Box, and Slider.

== Description ==

Nuvora AIO Blocks gives you 6 powerful, beautifully designed blocks for the WordPress block editor. Each block has multiple styles and full design controls — built natively for the block editor.

**Included Blocks:**

🔢 **Nuvora Counter Block**
Animated count-up counter with 5 styles, 12 icons, prefix/suffix, easing animations, and full typography/color controls.

💰 **Nuvora Pricing Table**
Fully customizable pricing card with 4 styles, gradient header, feature list, badge, CTA button, and strikethrough pricing.

💬 **Nuvora Testimonial Carousel**
Touch-friendly testimonial slider with avatars, star ratings, autoplay, swipe support, and 4 card styles.

🗂️ **Nuvora Advanced Tabs**
Advanced tabs block with title, description, and per-tab icon/color. 4 styles: Solid, Underline, Pills, Card Tabs.

⭐ **Nuvora Icon Box**
Icon boxes with heading and description. 4 card styles, icon position (top/left/right), shape options, and repeater for unlimited items.

🖼️ **Nuvora Slider**
Full-featured slider and carousel with 4 animation types, full-width/hero mode, captions, CTA buttons, autoplay, and Latest Posts support.

**Every block includes:**
* Multiple layout styles (4–5 per block)
* Full color controls
* Full typography controls (size, weight)
* Padding, border radius, and border controls
* Live preview in the block editor
* Clean, lightweight output — no bloat

== Installation ==

1. Upload the `nuvora-aio-blocks` folder to `/wp-content/plugins/`
2. Activate via the **Plugins** menu in WordPress.
3. In the block editor, search for **Nuvora** to find all blocks.

== Frequently Asked Questions ==

= Does this require any page builder? =
No. All blocks work natively with the WordPress block editor.

= Will you add more blocks? =
Yes! This plugin is designed to grow. More blocks are planned.

= Are these blocks responsive? =
Yes, all blocks are fully responsive and mobile-friendly.
